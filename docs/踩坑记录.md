1. sqlx::query 产出的是未经结构化映射的原始 Row，函数签名要求返回 Result<User, AppError>，必须使用 sqlx::query_as::<_, User>(...) 将行数据自动反序列化为实体。

**# sqlx migration run 重新建表**
原因：sqlx 会在 _sqlx_migrations 表里记录每个已执行迁移的 
checksum。你改了已经执行过的迁移文件 20260727201750，checksum 对不上，所以报：
~~~ text
migration 20260727201750 was previously applied but has been modified
~~~
**### 1.如果是本地开发，数据可以丢：直接重置数据库**
最快，不用手动删表。删整个库，_sqlx_migrations 也会一起没掉：
~~~ sql
sqlx database drop -y
sqlx database create
sqlx migrate run
或者一步到位： 删库 → 建库 → 跑迁移
sqlx database reset -y
~~~
**### 2. 如果是生产/共享库/不想丢数据：不要删表，新增迁移**
不要动旧文件，然后新增一个迁移来 ALTER TABLE：
~~~ sql
# 恢复旧迁移文件，假设用 git
git checkout -- migrations/20260727201750_*.sql

# 新增迁移
sqlx migrate add alter_your_table

# 编辑新生成的迁移文件，在里面写 ALTER TABLE ...
sqlx migrate run
~~~
**这是 sqlx 的正确用法：已经执行过的迁移不要改，表结构变更用新迁移。**
